# Q70 — JPA vs Hibernate: What's the difference?

## Questions

1. What is JPA? What is Hibernate? Which one is the specification, and which is the implementation?
2. Can you swap Hibernate for another JPA provider (e.g., EclipseLink)? What would need to change in a Spring Boot project?
3. When you use `@Entity`, `EntityManager`, `@OneToMany` etc. — are those JPA or Hibernate annotations? When would you use Hibernate-specific annotations instead?
4. What does Spring Data JPA add on top of JPA? How does it relate to Hibernate?
5. If someone says "we use JPA" and another says "we use Hibernate" for the same project, are they both right? Explain.
